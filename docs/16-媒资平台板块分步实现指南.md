## 一、本板块做什么

把 Lite VOD 从「只转 mp4」扩成书城可对接的**通用媒资**：视频能力保持不变，新增文档原件、**切章写回**、按对象签名。

**本仓做完即可单独验收**，不必等书城代码。书城用 HTTP 调这里的契约（见第四章）。

| 做 | 不做 |
| --- | --- |
| `asset_type`、DOCUMENT / CHAPTER / IMAGE | 用户登录、借阅、哪几章免费 |
| Worker `SPLIT_CHAPTER`，一章一个 `fileId` | 笔记、AI、图书元数据 |
| `GET .../chapters`、对象签名 / 内部拉文本 | 书城目录表、试看业务码 5103 |
| Compose 端口让位，方便与书城同机 | 改书城仓库 |

口诀：**只认识 fileId，不认识 userId。**

## 三、本机端口（与书城同机时）

书城默认占用 `3306` / `5672` / `15672`。媒资建议：

| 服务 | 映射 |
| --- | --- |
| MySQL | `3307:3306`，库 `lite_vod` |
| RabbitMQ | `5673:5672`，管理台 `15673:15672` |
| API | `8080` |
| 播放 Nginx | `8089:80` |
| MinIO | `9000` / `9001` |

产出：`lite-vod/.env.example` 或 `docker-compose.override.example.yml`。`VOD_PLAY_PUBLIC_BASE=http://localhost:8089`。

无书城时仍可用默认口，但合入前要能按上表切换。

## 四、对外契约（冻结给书城）

书城 Client 只依赖下列接口。路径前缀保持 `/vod`。

### 4.1 已有（回归必过）

```text
GET  /vod/health
GET  /vod/signature/upload
POST /vod/signature/upload/multipart
POST /vod/uploads/{fileId}/complete
POST /vod/medias
GET  /vod/medias/{fileId}
GET  /vod/medias
GET  /vod/signature/play?fileId=&preview=
DELETE /vod/medias/{fileId}
```

`POST /vod/medias` 现有 body：`fileId`、`filename`、`progressive`、`previewSeconds`。扩展只**加字段**。

### 4.2 本板块新增 / 扩展

**上传凭证**可带类型：

```text
GET /vod/signature/upload?assetType=DOCUMENT
```

缺省 `assetType=VIDEO`，旧 Demo 页不用改。

**commit 增量字段**（均可选）：

```json
{
  "fileId": "uuid",
  "filename": "redis.md",
  "assetType": "DOCUMENT",
  "splitRule": "MARKDOWN",
  "progressive": null,
  "previewSeconds": null
}
```

`splitRule`：`MARKDOWN` | `TXT_CHAPTER`。仅 `DOCUMENT` 有效。

**媒资 DTO 增量**（旧客户端忽略未知字段）：

```json
{
  "fileId": "...",
  "assetType": "DOCUMENT",
  "mimeType": "text/markdown",
  "parentFileId": null,
  "chapterNo": null,
  "status": "FINISHED",
  "filename": "redis.md"
}
```

**子章目录**：

```text
GET /vod/medias/{sourceFileId}/chapters
```

```json
{
  "sourceFileId": "...",
  "chapters": [
    {
      "chapterNo": 1,
      "title": "持久化",
      "fileId": "chap-uuid-1",
      "wordCount": 1200,
      "assetType": "CHAPTER"
    }
  ]
}
```

父任务未完成：`200` 且 `chapters: []`，或 `409`（二选一，选定后写进测试；推荐 **200 + 空数组**，书城轮询）。

**上传 / commit（生产走 internal，方案 B；验权在书城）**：

```text
GET  /internal/medias/upload-signature?assetType=DOCUMENT
POST /internal/medias
Header: X-Internal-Token: {与书城约定}
```

公开 `GET /vod/signature/upload`、`POST /vod/medias` 仅本地 debug。

**对象签名**（DOCUMENT / CHAPTER / IMAGE；debug）：

```text
GET /vod/signature/object?fileId=&ttl=60
```

返回限时 GET URL。`assetType=VIDEO` → **400**。字节由调用方直打 MinIO。

**内部读对象短链**（书城 BFF 生产读章）：

```text
GET /internal/medias/{fileId}/object-url?ttl=60
Header: X-Internal-Token: {与书城约定}
```

返回短链 JSON；BFF 再 GET MinIO。无 Token → 401。**不在媒资 api 内反代正文。**

**播放签名**：`assetType≠VIDEO` → **400**。

**删除 DOCUMENT**：级联删子 CHAPTER 对象与行；处理中 → 409（与现网视频删除一致）。

### 4.3 切章规则（Worker）

| `splitRule` | 切分 |
| --- | --- |
| `MARKDOWN` | 行首 `#{1,2}` + 空格 |
| `TXT_CHAPTER` | `第[一二三四五六七八九十0-9]+章` |

对象键：`chap/{sourceFileId}/{nnn}.md`（三位序号）。`parent_file_id=sourceFileId`，`chapter_no` 从 1。

无法切出至少 1 章：父 `status=失败`，`error_msg` 可读，不写空 CHAPTER。

## 五、数据模型（媒资库）

在现表 **ALTER**，不要重建、不要改坏旧 VIDEO 行（`asset_type` 默认 `VIDEO`）。

```sql
ALTER TABLE media
  ADD COLUMN asset_type      VARCHAR(16)  NOT NULL DEFAULT 'VIDEO'
    COMMENT 'VIDEO/DOCUMENT/CHAPTER/IMAGE/AUDIO/SUBTITLE' AFTER file_id,
  ADD COLUMN mime_type       VARCHAR(128) NULL AFTER filename,
  ADD COLUMN parent_file_id  VARCHAR(64)  NULL
    COMMENT 'CHAPTER 挂 DOCUMENT' AFTER mime_type,
  ADD COLUMN chapter_no      INT          NULL COMMENT 'CHAPTER 序号',
  ADD COLUMN page_count      INT          NULL,
  ADD COLUMN extract_key     VARCHAR(512) NULL;

CREATE INDEX idx_media_parent ON media (parent_file_id);
```

`media_task.type` 增加：`EXTRACT_TEXT`、`SPLIT_CHAPTER`、`THUMBNAIL`。

## 六、分期（L0～L5）

每阶段可单独演示；**L5 必须含视频回归**。

| 阶段 | 名称 | 周期 | 完成标准 |
| --- | --- | --- | --- |
| **L0** | 端口与脚本 | 0.5 天 | 与书城默认口不冲突的 Compose 示例 |
| **L1** | `asset_type` | 1 天 | 旧 mp4 仍是 VIDEO；DTO 带类型 |
| **L2** | DOCUMENT 上传完成 | 1～2 天 | txt/md 不走 FFmpeg HLS |
| **L3** | 切章写回 | 2～3 天 | `GET .../chapters` 有序；MinIO 有 `chap/` |
| **L4** | 对象签名 + 内部拉文本 | 1 天 | 单章可读；VIDEO 调 object → 400 |
| **L5** | IMAGE + 回归 + 删除级联 | 1～2 天 | 封面可选；T1～T8 视频仍过 |

### L0

```text
□ override / .env.example 写明 3307、5673、8089
□ 文档注明 VOD_PLAY_PUBLIC_BASE
```

### L1

```text
□ 列默认 VIDEO，旧数据无需手工 UPDATE
□ GET /vod/medias/{id} 含 assetType
□ 未传 assetType 的上传仍按视频 PROCEDURE
```

### L2

```text
□ commit assetType=DOCUMENT 后 status=完成（或进入切章，见 L3）
□ 不生成 index.m3u8
□ GET /vod/signature/play 对该 fileId 返回 400
```

L2 与 L3 可合并：DOCUMENT commit 直接进切章队列。

### L3

```text
□ 3～5 章 Markdown 样本切出对应 CHAPTER 行
□ GET /vod/medias/{source}/chapters 按 chapterNo 排序
□ 子对象可在 MinIO 控制台看到
□ 切不出章 → 父失败，无脏子行
```

### L4

```text
□ GET /vod/signature/object 可 wget 到章文本（debug）
□ GET /internal/medias/upload-signature + Token；POST /internal/medias + Token
□ GET /internal/medias/{chapterFileId}/object-url 有 Token 成功、无 Token 401
□ ttl 过期后 403（与现有播放验签风格一致即可）
```

### L5

```text
☑ IMAGE 上传完成（无 HLS）
☑ 删除 DOCUMENT 后子 CHAPTER 与对象消失
□ 视频：上传 → 转码 → preview 播放 → 删除（对照步骤 15，联调）
```

## 七、Worker 分流要点

```text
VIDEO     → 现有 PROCEDURE（禁止改默认行为）
DOCUMENT  → SPLIT_CHAPTER（md/txt）；PDF 可先 EXTRACT_TEXT 再切（可二期）
IMAGE     → 可选缩略图，失败仍 PROCESSED
CHAPTER   → 禁止从 /vod/signature/upload 单独创建
```

PDF 首期可声明「暂不切、status=完成、chapters 为空」，书城改传 MD。不要让 PDF 卡死视频队列。

CPU：切章与 FFmpeg **不要抢同一并发槽**。可用独立队列 `vod.document.split` 或限制 split 并发为 1。

## 八、本板块自测脚本（不依赖书城）

准备 `samples/redis-preview.md`（至少 3 个二级标题）。

```text
1. GET /internal/medias/upload-signature?assetType=DOCUMENT + Token
2. PUT 预签名 URL，body 为样本文件
3. POST /internal/medias  { fileId, filename, assetType, splitRule: MARKDOWN } + Token
4. 轮询 GET /vod/medias/{fileId} 至 FINISHED
5. GET /vod/medias/{fileId}/chapters  → 长度 ≥ 3
6. GET /internal/medias/{第一章 fileId}/object-url + Token → 拿 objectUrl → GET MinIO 得正文
7. GET /vod/signature/play?fileId={source} → 400
8. 再走一条旧 mp4 闭环，确认未回归
```

把 fileId 列表记到 [附录-联调样例](./16-媒资平台板块/附录-联调样例.md)（可手写，勿提交密钥）。书城板块用同一份样例对接。

## 九、错误语义（媒资 HTTP）

| HTTP | 场景 |
| --- | --- |
| 400 | 对 CHAPTER/DOCUMENT 要 play；对 VIDEO 要 object |
| 401 | 内部拉文本缺 Token |
| 404 | fileId 不存在 |
| 409 | 处理中删除；或 commit 重复非法状态（保持现网） |
| 501 | 未实现的 assetType（如 AUDIO） |

不要返回书城业务码 51xx。
