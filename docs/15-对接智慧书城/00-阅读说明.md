## 文档目的

说明 Lite VOD 媒资平台如何与 **智慧书城** 配合，形成「实体书 / 电子书 + 配套视频 + AI 笔记」的学习闭环。

**边界原则**（与对接天机学堂一致）：

- **Lite VOD**：上传、转码、**切章写回**、存储、播放 / 对象签名、试看 `exper`
- **智慧书城**：用户登录、图书与电子书**目录**、借阅权限、业务页与 AI Agent
- **Lite VOD 不负责**：课表、订单、书架架位、笔记内容、哪几章免费

## 何时开始

同时满足再开工对接：

1. Lite VOD 首期闭环：上传 → 转码完成 → 签名播放 → 删除（见 [步骤 15](../05-分步实现指南/15-测试用例落地.md)）
2. 智慧书城可正常启动（JWT 登录、图书模块可用）
3. 已明确首期场景：**图书配套导读视频**（5～15 分钟 mp4），而非长课程平台

---

## 推荐实施顺序

```text
Lite VOD 首期闭环（05 目录 01～15）
  → M0 双端联调环境与 JWT 对齐
  → M1 书城侧 media_ref 关联表 + 管理端绑定 fileId
  → M2 用户端「图书详情 → 配套视频」+ 试看 exper
  → M3 借阅/购书解锁完整播放（书城鉴权 → 向 VOD 要签名）
  → M4 字幕 + AI 视频笔记（可选，依赖书城 AI 模块）
  → M5 前端阅读器 / 播放页统一演示
```

---

## 成功标准（对接 MVP）

1. 管理端在 Lite VOD 上传导读视频，在书城管理端把 `fileId` 绑定到 `book_id`
2. 书城图书详情页展示「配套视频」，未借阅用户试看前 N 秒
3. 借阅中或已购用户可播放完整 HLS
4. 过期签名 / 未授权用户无法拉取完整流
5. 两项目可独立部署，通过 HTTP + 共享 JWT Secret 或 BFF 聚合
