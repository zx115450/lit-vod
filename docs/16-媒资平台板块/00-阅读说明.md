## 本板块做什么

把 Lite VOD 从「只转 mp4」扩成书城可对接的**通用媒资**：视频能力保持不变，新增 DOCUMENT 原件、**切章写回 CHAPTER**、对象签名与内部拉文本。

**口诀：只认识 fileId，不认识 userId。**

| 做 | 不做 |
| --- | --- |
| `asset_type`、DOCUMENT / CHAPTER / IMAGE | 用户登录、借阅、哪几章免费 |
| Worker `SPLIT_CHAPTER`，一章一个 `fileId` | 笔记、AI、书城目录表 |
| `GET .../chapters`、对象签名 / 内部拉文本 | 试看业务码 5103 |

## 使用方式

1. 确认 [05 步骤 15](../05-分步实现指南/15-测试用例落地.md) 视频 T1～T8 仍可通过（回归基线）
2. 从 **L0** 做到 **L5**，每步末尾「完成标准」全部勾选再进下一步
3. 契约细节以 [总纲第四章](../16-媒资平台板块分步实现指南.md#四对外契约冻结给书城) 为准；步骤文档只讲「改哪里、怎么验」
4. L3 切章写回是核心难点，可与 L2 合并开发，但验收仍分步
5. 样例 fileId 记入 [附录-联调样例](./附录-联调样例.md)，供书城 B2 对接

## 推荐联调拓扑（当前）

```text

本机                vod-api :8080 · vod-worker :8082
```

本机**不要**再起与 104 冲突的 MySQL/Redis 容器。详见 [虚拟机环境说明](../../../docs/虚拟机环境说明-192.168.150.104.md)。
