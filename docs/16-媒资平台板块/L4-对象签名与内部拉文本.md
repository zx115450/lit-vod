# L4：对象签名与内部拉文本

> **阶段**：L4 · **周期**：1 天  
> **目标**：DOCUMENT / CHAPTER / IMAGE 可走对象签名；书城 BFF 用 Internal-Token 拿短链后**直打 MinIO**；VIDEO 调 object / 非 VIDEO 调 play 均 400。  
> **上一篇**：[L3 切章写回](./L3-切章写回.md)　**下一篇**：[L5 IMAGE 回归与删除级联](./L5-IMAGE回归与删除级联.md)

---

## 本步要做什么

阅读链路：**书城鉴权 → BFF 向媒资要短链 → BFF/工具直拉 MinIO**。

原则：**签发在业务，字节不过 vod-api**（与播放签名对称）。

1. **限时签名 URL**：`GET /vod/signature/object`（管理 / debug）
2. **内部签发**（生产推荐）：`/internal/medias/{fileId}/object-url` + `X-Internal-Token`

---

## 对象签名

```text
GET /vod/signature/object?fileId={id}&ttl=60
```

| 条件 | 结果 |
| --- | --- |
| `assetType` ∈ DOCUMENT / CHAPTER / IMAGE | 200，返回 MinIO 预签名 GET URL |
| `assetType == VIDEO` | **400** |
| fileId 不存在 | 404 |
| ttl 过期后访问 URL | MinIO 拒绝（预签名失效） |

实现：`MinioStorage.presignedGet`，路径为 `media.object_key`（CHAPTER 为 `chap/...`）。

响应示例：

```json
{
  "fileId": "chap-xxx",
  "objectUrl": "http://minio:9000/vod/chap/.../001.md?X-Amz-Algorithm=...",
  "objectKey": "chap/{source}/001.md",
  "assetType": "CHAPTER",
  "expireAt": 1710000060
}
```

生产读章**不要**把该 URL 下发给未授权浏览器；公开面建议后续加管理鉴权。

---

## 内部接口（带 Token，方案 B）

用户 / ADMIN 验权在**书城**；媒资只校验 `X-Internal-Token`。

```text
# 上传（书城管理端鉴权后调用）
GET  /internal/medias/upload-signature?assetType=DOCUMENT
POST /internal/medias/upload-signature/multipart   # 大文件分片；需 VOD_UPLOAD_MULTIPART_ENABLED
POST /internal/medias/uploads/{fileId}/complete
POST /internal/medias/uploads/{fileId}/abort
POST /internal/medias                         # body 同公开 commit

# 读对象短链（书城读章鉴权后调用）
GET  /internal/medias/{fileId}/object-url?ttl=60
Header: X-Internal-Token: {与书城约定}
```

| 条件 | 结果 |
| --- | --- |
| Token 正确 | 200 |
| Token 缺失/错误 | **401** |
| object-url 且 VIDEO | 400 |

公开 `/vod/signature/upload`、`POST /vod/medias`、`/vod/signature/object` 仍保留给本地 debug；**书城生产 Client 应打 internal**。

配置：

```yaml
vod:
  internal:
    token: ${VOD_INTERNAL_TOKEN:dev-internal-token-change-me}
    enabled: ${VOD_INTERNAL_ENABLED:true}
```

`enabled=false` 时跳过 Token 校验（仅本地）。不影响 `/internal/play-auth`。

书城 BFF：

- 小文件上传：`createUploadSignature` → internal upload-signature → 浏览器 PUT MinIO → `commit` → internal POST
- 大文件分片：internal `upload-signature/multipart` → 各片 PUT MinIO → `uploads/{fileId}/complete` → internal commit
- 读章：`fetchObjectText` = object-url → **HttpClient GET MinIO**

**分工**

| 接口 | 谁用 |
| --- | --- |
| `/vod/signature/upload`、`/vod/signature/upload/multipart`、`POST /vod/medias`、`/vod/signature/object` | 媒资本地 debug |
| `/internal/medias/upload-signature`、`.../multipart`、`uploads/*/complete|abort`、`POST /internal/medias`、`.../object-url` | 书城生产（+ Token） |

---

## 与书城契约

环境变量对齐（两侧同一随机串）：

```yaml
# 书城
bookstore.media.lite-vod.internal-token: ${BOOKSTORE_MEDIA_TOKEN:}

# vod-api
vod.internal.token: ${VOD_INTERNAL_TOKEN:}
```

**不要**用用户 JWT 打媒资；**不要**把 object URL 给未授权前端。

---

## 验证

```bash
export TOKEN=dev-internal-token-change-me   # 或你的 VOD_INTERNAL_TOKEN
export CHAP=fileId-from-L3

# 对象签名（debug）
curl "http://localhost:8080/vod/signature/object?fileId=$CHAP&ttl=60"
# wget "$(jq -r .objectUrl)" → 应拿到 md 正文

# 内部签发
curl -H "X-Internal-Token: $TOKEN" \
  "http://localhost:8080/internal/medias/$CHAP/object-url"

# 负例
curl "http://localhost:8080/vod/signature/object?fileId={mp4FileId}" → 400
curl "http://localhost:8080/vod/signature/play?fileId={documentFileId}" → 400
curl "http://localhost:8080/internal/medias/$CHAP/object-url" → 401
```

## 完成标准

- [x] `GET /vod/signature/object` 可 wget 到章文本（经返回的 `objectUrl`；debug）
- [x] internal `object-url` / `upload-signature` / `POST /internal/medias` 有 Token 成功、无 Token 401
- [x] internal multipart（`upload-signature/multipart`、`uploads/*/complete|abort`）有 Token；关闭开关时仍 501（同公开面）
- [x] VIDEO 调 object → 400；DOCUMENT 调 play → 400（L2 已有，回归）
- [x] ttl 过期后签名 URL 不可用（MinIO 预签名）

> 实现落点：`presignedGet` / `presignedPut`；`ObjectSignatureService`；
> internal：`upload-signature`（整对象 + multipart）、`POST /internal/medias`、`object-url` + Token（方案 B）；
> 公开 `/vod` 签发仅 debug。**不反代章正文。**
