## 端到端 curl 流程

```bash
BASE=http://localhost:8080
TOKEN=your-internal-token   # 与 VOD_INTERNAL_TOKEN / BOOKSTORE_MEDIA_TOKEN 一致

# 1. 上传凭证（生产：internal + Token；debug 仍可用 /vod/signature/upload）
curl -H "X-Internal-Token: $TOKEN" \
  "$BASE/internal/medias/upload-signature?assetType=DOCUMENT"

# 2. PUT 到返回的预签名 URL（本地文件 samples/redis-preview.md）

# 3. commit（生产：internal）
curl -X POST "$BASE/internal/medias" \
  -H "Content-Type: application/json" \
  -H "X-Internal-Token: $TOKEN" \
  -d '{"fileId":"<FILE_ID>","filename":"redis-preview.md","assetType":"DOCUMENT","splitRule":"MARKDOWN"}'

# 4. 轮询父媒资
curl "$BASE/vod/medias/<SOURCE_FILE_ID>"

# 5. 章目录
curl "$BASE/vod/medias/<SOURCE_FILE_ID>/chapters"

# 6. 内部签发短链（生产读章；再由调用方 GET MinIO）
curl -H "X-Internal-Token: $TOKEN" "$BASE/internal/medias/<CHAPTER_FILE_ID>/object-url"

# 7. 负例：对 DOCUMENT 要播放
curl "$BASE/vod/signature/play?fileId=<SOURCE_FILE_ID>"

# （可选）大文件分片：需 VOD_UPLOAD_MULTIPART_ENABLED=true
# curl -X POST -H "X-Internal-Token: $TOKEN" -H "Content-Type: application/json" \
#   "$BASE/internal/medias/upload-signature/multipart" \
#   -d '{"filename":"lesson01.mp4","contentType":"video/mp4","contentLength":26214400,"partSize":10485760}'
# # 各片 PUT 到 parts[].url 后：
# curl -X POST -H "X-Internal-Token: $TOKEN" -H "Content-Type: application/json" \
#   "$BASE/internal/medias/uploads/<FILE_ID>/complete" \
#   -d '{"uploadId":"<UPLOAD_ID>","parts":[{"partNumber":1,"etag":"\"a\""},{"partNumber":2,"etag":"\"b\""}]}'
# # 中止：POST .../uploads/<FILE_ID>/abort  {"uploadId":"..."}
```

## HTTP 错误语义（媒资侧）

| HTTP | 场景 |
| --- | --- |
| 400 | CHAPTER/DOCUMENT 调 `signature/play`；VIDEO 调 `signature/object` |
| 401 | internal content 缺 Token 或 Token 错误 |
| 404 | fileId 不存在 |
| 409 | 处理中删除；非法重复 commit（保持现网） |
| 501 | 未实现 assetType（如 AUDIO） |

**不要**返回书城业务码 51xx / 5103（试看拦截在书城 BFF）。
