## 本步要做什么

1. 明确两种联调模式并写入示例配置
2. 保证 `vod-api` / `vod-worker` 能连上 MySQL、RabbitMQ、MinIO
3. 播放 Nginx 与 `VOD_PLAY_PUBLIC_BASE` 文档化（视频回归仍需要）

---

## 模式 A：远程中间件（当前推荐）

中间件在 **192.168.150.104**，本机只跑 Java。

| 服务 | 地址 | 账号 |
| --- | --- | --- |
| MySQL | `192.168.150.104:3306` | root / 1234，库 `lite_vod` |
| RabbitMQ | `192.168.150.104:5672` | root / 1234，vhost `/` |
| MinIO | `http://192.168.150.104:9000` | root / root1234，桶 `vod` |

`vod-api`、`vod-worker` 的 `application.yml` 已默认指向 104。启动：

```bash
# vod-api 8080
# vod-worker 8082（避免与书城 8081 冲突）
```

完整说明：[虚拟机环境说明](../../../docs/虚拟机环境说明-192.168.150.104.md)

---

## 模式 B：本机 Compose（与书城同机）

书城默认占 `3306` / `5672` / `15672`。媒资需让位：

| 服务 | 映射 |
| --- | --- |
| MySQL | `3307:3306`，库 `lite_vod` |
| RabbitMQ | `5673:5672`，管理台 `15673:15672` |
| API | `8080` |
| 播放 Nginx | `8089:80` |
| MinIO | `9000` / `9001` |

**产出物**（本步应新增到仓库）：

- `lite-vod/.env.example` 或 `docker-compose.override.example.yml`
- 注释 `VOD_PLAY_PUBLIC_BASE=http://localhost:8089`

环境变量示例：

```env
MYSQL_HOST=127.0.0.1
MYSQL_PORT=3307
RABBITMQ_HOST=127.0.0.1
RABBITMQ_PORT=5673
MINIO_ENDPOINT=http://127.0.0.1:9000
VOD_PLAY_PUBLIC_BASE=http://localhost:8089
```

## 操作步骤

### 1. 选定模式并验证连通

```bash
# 远程模式
curl -sf http://192.168.150.104:9000/minio/health/live
curl -sf http://127.0.0.1:8080/vod/health   # 本机 api 启动后
```

### 2. 确认 Worker 端口

`vod-worker/src/main/resources/application.yml` 中 `server.port: 8082`，与书城 8081 错开。

### 3. 编写 override 示例（模式 B）

在 `lite-vod/docker-compose.override.example.yml` 中只覆盖**端口映射**，不要改业务镜像名。README 中说明：无书城时用默认口，有书城时 copy override。

### 4. 更新 lite-vod README 一段「与书城同机」

指向本文件与 [总纲](../16-媒资平台板块分步实现指南.md#三本机端口与书城同机时)。
