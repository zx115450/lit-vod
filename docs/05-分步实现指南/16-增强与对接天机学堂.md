## 何时开始

仅当步骤 15 的 T1～T8 已通过。本步每一项都可独立开分支，不要混在首期 PR 里。

## 16.1 分片上传

大文件走 S3 Multipart：`CreateMultipartUpload` + 每片预签名 + `CompleteMultipartUpload`。  
API 可新增 `POST /vod/signature/upload/multipart`，前端按 PartNumber 上传。  
`POST /vod/medias` 的 HeadObject 逻辑不变。

## 16.2 多码率

FFmpeg 产出 360p / 720p / 1080p 多套 HLS，再写 `master.m3u8`。  
`media_url` 指向 master。播放器自动切档。注意 Worker CPU 与磁盘成倍增加。

## 16.3 试看 L2

转码时额外生成 `preview.m3u8`（仅前 N 秒切片）。签发时若 `exper>0` 则 `playUrl` 指向 preview。安全性高于 L0/L1。

## 16.4 对接 `tj-media`

保持门面不变：

```text
IMediaStorage
  ├─ TencentMediaStorage
  └─ LiteVodMediaStorage
```

| 现有方法 | Lite VOD |
| --- | --- |
| `getUploadSignature()` | `GET /vod/signature/upload` |
| `getPlaySignature(fileId, userId, freeExpire)` | `GET /vod/signature/play`（`freeExpire` → `exper`） |
| `queryMediaInfos(fileId)` | `GET /vod/medias/{fileId}` |
| `deleteFile(fileId)` | `DELETE /vod/medias/{fileId}` |
| `PullEventTask` | Webhook 或 `GET /vod/events/pull` |

配置示例：

```yaml
tj:
  media:
    platform: lite-vod
    lite-vod:
      base-url: http://lite-vod-api:8080
      play-secret: ${VOD_PLAY_SECRET}
```

播放鉴权链路不变：`sectionId` → course → learning → 再向 Lite VOD 要签名。  
Lite VOD **仍然不负责课表**。

对照代码路径见实现文档第十六章。
