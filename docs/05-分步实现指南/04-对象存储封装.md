# 步骤 04：对象存储封装

> 分期：Phase 1 前置。  
> 目标：在 `vod-api`（及后续 worker 复用）中封装 MinIO：预签名 PUT、HeadObject、下载、上传。  
> 上一篇：[工程骨架](./03-工程骨架.md)　下一篇：[申请上传凭证](./05-申请上传凭证.md)

## 本步要做什么

写 `storage` 包，用集成测试或临时接口验证 MinIO 连通。业务 Controller 仍不对外开放上传流程。

SDK 方法、预签名注意点和测试用法见 [MinIO Java SDK 使用说明](../MinIO-Java-SDK.md)。

## 路径约定（实现文档第六章）

```text
bucket: vod
  raw/{fileId}/source.mp4
  hls/{fileId}/index.m3u8
  hls/{fileId}/segment_000.ts
  cover/{fileId}.jpg
```

封装时用常量或小型 `ObjectKeys` 工具生成上述 key，避免各处手拼字符串。

## 操作步骤

### 1. 引入 MinIO Java SDK

`vod-api` 与 `vod-worker` 都需要（worker 第 09 步用）。可抽公共模块，演示工程也可各写一份相同客户端配置。

配置项：

- `MINIO_ENDPOINT`：容器内用 `http://minio:9000`，本机调试可用 `http://localhost:9000`
- `MINIO_ROOT_USER` / `MINIO_ROOT_PASSWORD`
- `MINIO_BUCKET=vod`

### 2. 实现最小方法集

| 方法 | 用途 | 谁用 |
| --- | --- | --- |
| `presignedPut(objectKey, expiry)` | 申请上传凭证 | api |
| `head(objectKey)` | commit 时确认对象存在 | api |
| `statSize(objectKey)` | 写入 `media.size` | api |
| `download(objectKey, localPath)` | 转码前拉原片 | worker |
| `uploadFile(objectKey, localPath)` | 回传 HLS / 封面 | worker |
| `removePrefix(prefix)` | 删除媒资 | api（第 14 步） |

本步至少完成前 3 个；download/upload 可先空实现或写好待第 09 步调用。

### 3. 预签名注意点

- 使用 `presignedPutObject`，有效期 30～120 分钟
- 返回给浏览器的 `uploadUrl` 必须是 **浏览器能访问的地址**（通常是 `localhost:9000` 或 Nginx 映射），不是容器内主机名 `minio`
- 可配置 `MINIO_PUBLIC_ENDPOINT` 专门生成预签名 Host

### 4. 验证

写一个仅开发环境开启的测试：

1. 生成 `raw/dev-test/source.mp4` 的 PUT URL
2. 用 curl 上传小文件
3. `head` 成功

```bash
curl -X PUT --upload-file ./tiny.mp4 "$UPLOAD_URL"
```

## 完成标准

- [ ] 预签名 URL 能从宿主机 PUT 成功
- [ ] HeadObject 能读到对象
- [ ] key 生成符合 `raw/{fileId}/source.mp4` 约定
- [ ] 无匿名公开 bucket

- 不做 Multipart 分片（第 16 步）
