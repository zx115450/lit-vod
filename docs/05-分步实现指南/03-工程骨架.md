# 步骤 03：工程骨架

> 分期：Phase 1 前置。  
> 目标：建好 `vod-api`、`vod-worker` 两个 Spring Boot 模块，能随 Compose 启动并健康检查。  
> 上一篇：[数据模型初始化](./02-数据模型初始化.md)　下一篇：[对象存储封装](./04-对象存储封装.md)

## 本步要做什么

搭空壳：依赖、包结构、配置、Dockerfile。不实现业务接口。

## 技术选型（与实现文档一致）

- Java 17 + Spring Boot 3
- 包名示例：`com.example.vod`
- 构建：Maven 多模块，或两个独立工程（演示用独立工程更简单）


## 操作步骤

### 1. 初始化 `vod-api`

依赖建议：

- `spring-boot-starter-web`
- `spring-boot-starter-jdbc` 或 MyBatis / Spring Data JPA（任选其一，全工程统一）
- `mysql-connector-j`
- 先不要加 MinIO / AMQP，下一步再加

提供：

- `GET /actuator/health` 或 `GET /vod/health` 返回 `ok`
- `application.yml` 读取 `MYSQL_*` 环境变量

### 2. 初始化 `vod-worker`

同样 Java 17。本步只启动、连库（可选）、打印「worker started」。  
FFmpeg 调用放到第 09 步。

### 3. Dockerfile

- `vod-api`：常规 JRE 镜像即可
- `vod-worker`：**必须能安装 ffmpeg**（Debian/Ubuntu 包或静态二进制）。本步先写好 Dockerfile，即使暂时不跑转码

### 4. 接入 Compose

增加服务：

| 服务 | 端口 |
| --- | --- |
| vod-api | 8080 |
| vod-worker | 无对外端口 |

`depends_on`：mysql（api/worker）、rabbitmq（worker 第 08 步再强依赖也可）。

### 5. 验证

```bash
docker compose up -d --build
curl http://localhost:8080/vod/health
```

## 完成标准

- [ ] `vod-api` 容器启动成功，健康接口 200
- [ ] `vod-worker` 容器启动成功（日志无循环崩溃）
- [ ] 配置全部来自环境变量，仓库内无密码

## 本步不做

- 不写上传 / 播放接口
- 不调 MinIO
- 不消费 MQ
