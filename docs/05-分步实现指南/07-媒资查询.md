# 步骤 07：媒资查询

> 分期：Phase 1。  
> 目标：实现按 `fileId` 查询与分页列表，管理端能看到媒资状态。  
> 上一篇：[确认上传与媒资落库](./06-确认上传与媒资落库.md)　下一篇：[转码任务投递](./08-转码任务投递.md)

## 本步要做什么

对齐腾讯 `DescribeMediaInfos` 的常用子集，给管理端列表和详情。

## 接口契约

### 详情

- `GET /vod/medias/{fileId}`
- 404：无此媒资
- 200：`MediaDTO`

建议字段：

- `fileId`、`filename`、`status`、`statusText`
- `objectKey`、`mediaUrl`、`coverUrl`
- `duration`、`size`
- `errorMsg`
- `createTime`、`updateTime`

转码完成前 `mediaUrl` / `coverUrl` / `duration` 可为 null。

### 分页列表

- `GET /vod/medias?pageNo=&pageSize=&name=`
- `name` 对 `filename` 模糊查询
- 默认按 `create_time` 倒序

## 操作步骤

1. Repository：`findByFileId`、`pageByFilename`
2. 枚举转前端可读文案（上传中 / 已上传 / 处理中 / 已完成 / 失败）
3. 不要把 MinIO 内部 endpoint 直接当播放地址返回；播放入口等第 10 步签发签名 URL。详情里可返回相对路径 `hls/{fileId}/index.m3u8` 供调试

## 验证

- 对步骤 06 产生的 `fileId` 调详情，字段与库一致
- 分页：插入多条后 `pageSize=2` 翻页正确
- `name` 过滤生效

## 完成标准

- [ ] 详情 200 / 404 行为正确
- [ ] 列表分页与文件名筛选可用
- [ ] 不泄露 MinIO 账号或预签名密钥
