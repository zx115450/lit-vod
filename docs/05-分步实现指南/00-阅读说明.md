# 分步实现指南：阅读说明

> 本文档把 [轻量版云点播实现文档](../04-轻量版云点播-Lite-VOD-实现文档.md) 拆成「一步一个文档」。  
> 每步只做一件可验收的事；做完再进入下一步。

## 使用方式

1. 未接触过点播：先读 [前置知识](../03-点播与对象存储-前置知识.md)
2. 再通读实现文档第 1～4 章（目标、架构、技术栈、工程结构）
3. 按本目录从 `01` 做到 `15`
4. 每步末尾有「完成标准」：全部勾选后再开下一步
5. `15` 通过后建议做 `17`（CI/CD 工程化）；`16` 为增强与对接，首期可跳过
6. 闭环之余的知识补齐与实习方向：见 [扩展学习与实习准备](../10-扩展学习与实习准备.md)
7. 步骤 04 的 SDK 细节：见 [MinIO Java SDK 使用说明](../MinIO-Java-SDK.md)
8. 步骤 09 的进程调用：见 [Java 调用命令行程序使用指南](../Java-ProcessBuilder.md)
9. 步骤 09 的产物回传：见 [Worker 写回 MinIO 说明](../Worker-写回MinIO.md)
10. Nginx 入口与播放反代：见 [Nginx 使用说明](../Nginx使用说明.md)
11. Nginx 安装包目录：见 [Nginx 安装包目录说明](../Nginx安装包目录说明.md)

## 原则

- **不提前做二期**：分片上传、多码率、试看 L2 放到第 16 步
- **密钥不入库**：MinIO、MySQL、`VOD_PLAY_SECRET` 一律环境变量；CI Secrets 同理
- **一步一验收**：接口用 Postman / curl 验证；播放用浏览器验证
- **对照实现文档**：路径约定、状态机、API 契约以实现文档为准，步骤文档只讲「怎么做」
- **工程化可穿插**：业务闭环后用步骤 17 补流水线，勿与步骤 16 业务增强混在同一 PR

## 成功标准（全局）

与实现文档 1.3 节一致：

1. 管理端可直传视频并在媒资列表看到「处理完成」
2. 学员端用 `fileId` + 播放凭证能用 hls.js 流畅播放
3. 未授权 Token 或过期签名无法拉到完整流
4. `docker-compose` 一键拉起 API / Worker / MinIO / MQ / Nginx / MySQL
