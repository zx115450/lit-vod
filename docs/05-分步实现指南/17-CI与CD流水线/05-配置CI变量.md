# 05：配置 CI 变量

> 目标：把 Harbor 与 SSH 密钥放进 GitLab CI/CD Variables，yaml 里零明文。  
> 上一篇：[准备 Harbor](./04-准备Harbor.md)　下一篇：[Compose 改为可拉镜像](./06-Compose改为可拉镜像.md)

## 本步要做什么

路径：GitLab 项目 → Settings → CI/CD → Variables。  
敏感项勾选 **Masked**；一般不要勾 Expand（避免意外展开）。

## 变量表

| 变量名 | 用途 | 示例 |
| --- | --- | --- |
| `HARBOR_HOST` | 镜像仓库主机 | `harbor.example.com` |
| `HARBOR_PROJECT` | Harbor 项目名 | `lite-vod` |
| `HARBOR_USER` | 推送账号 | `robot$lite-vod+ci` |
| `HARBOR_PASSWORD` | 推送密码 | （Masked） |
| `DEPLOY_HOST` | 演示机 IP / 域名 | `10.0.0.20` |
| `DEPLOY_USER` | SSH 用户 | `deploy` |
| `DEPLOY_SSH_KEY` | 私钥全文（或 File 类型） | （Masked / File） |
| `DEPLOY_PATH` | 目标机 compose 目录 | `/opt/lite-vod` |

## 说明

- Runner 需能访问 Harbor 与演示机（内网 Runner 更贴近企业）
- SSH **公钥**事先放到演示机 `~/.ssh/authorized_keys`
- MySQL / MinIO / `VOD_PLAY_SECRET` 放在**目标机** `.env`，不要塞进 CI 变量，除非确有需要
- `DEPLOY_SSH_KEY` 若用 File 类型，Job 里路径在 `$DEPLOY_SSH_KEY`，按 GitLab 文档读取

## 完成标准

- [ ] 上表变量均已配置（部署若暂缓，可先只配 Harbor 四项）
- [ ] 密码类已 Masked
- [ ] 仓库文件中搜不到这些真实值

## 本步不做

- 不编写 deploy Job（见 07～08）
- 不在目标机落盘 compose（见 06、08）
