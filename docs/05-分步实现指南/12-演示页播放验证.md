# 步骤 12：演示页播放验证

> 分期：Phase 3。  
> 目标：静态页用 hls.js 播放签名 URL，确认流畅播放（成功标准第 2 条）。  
> 专题说明：[Nginx 使用说明](../Nginx使用说明.md)（静态页挂载与同域）。  
> 上一篇：[播放网关验签](./11-播放网关验签.md)　下一篇：[事件通知](./13-事件通知.md)

## 本步要做什么

做一个最小播放器页，不接天机学堂前端。用于验收，不是产品 UI。

## 页面行为

1. 输入 `fileId`，点击「申请播放」
2. 调用 `GET /vod/signature/play?fileId=`
3. 把返回的 `playUrl` 交给 hls.js
4. 显示错误（403、未转码完成）

可用 Video.js 替代，要求相同：必须走签名 URL，不能直连 MinIO。

## 操作步骤

### 1. 静态资源

放到 `nginx` 的 `html/` 或 `vod-api` 的 `resources/static/player.html`。  
演示页与 `/hls/` 尽量同域，减少 CORS。

### 2. 最小脚本逻辑

- 浏览器原生 HLS（Safari）可直接给 `video.src = playUrl`
- 其他浏览器：`Hls.isSupported()` 后 `hls.loadSource(playUrl)`

### 3. 端到端走查

用真实用户路径：

1. 申请上传凭证
2. 页面或脚本 PUT 到 MinIO（可继续用 Postman）
3. commit，等到 PROCESSED
4. 打开演示页播放

### 4. 安全抽查

- 播放中把 URL 的 `sign` 改坏，刷新应变失败
- Token 过期后无法继续拉 ts（或刷新后 403）

## 完成标准

- [ ] PROCESSED 视频可在 Chrome 用 hls.js 播放
- [ ] 进度条可拖动（切片齐全）
- [ ] 过期或篡改无法完整播放
- [ ] 未做课表、登录（属业务侧）

## 本步不做

- 不改 `tj-media`
- 不做 Abr 多码率切换
