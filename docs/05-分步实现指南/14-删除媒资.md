# 步骤 14：删除媒资

> 分期：收尾。  
> 目标：`DELETE /vod/medias/{fileId}` 删除对象与库记录（测试 T8）。  
> 上一篇：[事件通知](./13-事件通知.md)　下一篇：[测试用例落地](./15-测试用例落地.md)

## 本步要做什么

对齐腾讯删除文件。避免桶内残留 HLS 切片占磁盘。

## 接口契约

- `DELETE /vod/medias/{fileId}`
- 不存在：404 或 204（选定一种并文档化，建议 404）
- 成功：204 或 200

## 删除范围

MinIO 前缀：

- `raw/{fileId}/`
- `hls/{fileId}/`
- `cover/{fileId}.jpg`

库：

- 硬删 `media` + `media_task`（及事件表）
- 或软删 `deleted` 标志；对象仍要删，否则磁盘不回收

若任务 `RUNNING`：可拒绝删除（409）或先标记取消。首期建议：**PROCESSING 时 409**，避免 Worker 写回已删记录。

## 操作步骤

1. 实现 `removePrefix`（步骤 04 若未写，这里补齐）
2. 先删对象再删库，或同一事务外补偿：对象删失败则接口失败，避免库无记录但桶内仍有文件
3. 验证 T8：详情 404，MinIO 前缀为空

## 完成标准

- [ ] 对象与行均清理
- [ ] 处理中删除有明确策略
- [ ] 播放旧签名在删除后 404（对象不存在）
