# 步骤 11：播放网关验签

> 分期：Phase 3。  
> 目标：Nginx（或 Spring Filter）校验 `sign` / `e` 后，反代 MinIO 的 `vod/hls/` 与封面。  
> 专题说明：[Nginx 使用说明](../Nginx使用说明.md)。  
> 生产化加深（Filter → `auth_request` + 直反 MinIO）：[08-Nginx auth_request 播放网关](../06-工程化实践记录/08-Nginx-auth_request播放网关.md)。  
> 上一篇：[播放签名签发](./10-播放签名签发.md)　下一篇：[演示页播放验证](./12-演示页播放验证.md)

## 本步要做什么

公网不开放 MinIO 匿名读。播放请求必须带合法签名。`.ts` 与 `m3u8` 都要能过。

## 校验规则

1. 查询参数存在 `e`、`sign`
2. 当前时间 `< e`，否则 403（测试 T6）
3. 用与签发端相同的 HMAC 重算，恒等比较（防时序攻击可用 `MessageDigest.isEqual`）
4. 通过则 `proxy_pass` 到 `http://minio:9000/vod/hls/`

路径绑定：

- 推荐签名绑定目录前缀 `/hls/{fileId}/`，这样每个 ts 携带 **同一套** `e、exper、sign` 即可
- 签发 `path` 时若签的是完整 m3u8 路径，则 ts 请求要么改写 m3u8 补参数，要么验签时改为校验「请求 URI 是否以 `/hls/{fileId}/` 开头」且 `fileId` 来自签名原文

首期推荐 **目录前缀签名**：

```text
path=/hls/{fileId}/&e=...&exper=...
```

同时让 `playUrl` 仍指向 `index.m3u8?e&exper&sign`。验签取 URI 的目录部分。**签发与验签必须同一约定**，若第 10 步签的是全路径，本步不要改算法，只实现对应校验。

封面可选：`/cover/{fileId}.jpg` 同样验签，或仅内网管理端走预签名 GET。

## 实现选型

| 方案 | 适用 |
| --- | --- |
| `auth_request` + 旁路小接口 | 与 Java 算法完全复用，推荐 |
| OpenResty / njs 内嵌 HMAC | 少一次跳转，运维稍重 |
| Spring Cloud Gateway / Filter 代替 Nginx | 开发阶段最快 |

实现文档允许开发阶段用 Spring 代替 Nginx。演示闭环仍建议 Compose 里保留 Nginx 反代，鉴权可用 `auth_request` 打到 `vod-api` 的内部接口 `GET /internal/play-auth`。

## Nginx 示意

```nginx
location /hls/ {
    auth_request /_auth;
    proxy_pass http://minio:9000/vod/hls/;
    proxy_set_header Host minio:9000;
    proxy_hide_header x-amz-id-2;
    proxy_hide_header x-amz-request-id;
}

location = /_auth {
    internal;
    proxy_pass http://vod-api:8080/internal/play-auth;
    proxy_pass_request_body off;
    proxy_set_header Content-Length "";
    proxy_set_header X-Original-URI $request_uri;
}
```

内部接口根据 `X-Original-URI` 解析 path 与 query，验签，200 或 403。

MinIO 反代时注意 `proxy_pass` 路径拼接：`/hls/xxx` → 桶内 `hls/xxx`。

## CORS

若演示页与播放域名不同源，给 `/hls/` 加 CORS 头（含 `GET`）。签名参数在 query 里，注意不要用 `*` 搭配带 cookie 的模式。

## 验证

```bash
# 无签名
curl -i http://localhost/hls/{fileId}/index.m3u8
# 期望 401/403

# 合法 playUrl
curl -i "$PLAY_URL"
# 期望 200，body 为 #EXTM3U

# 过期 e
# 期望 403

# 改 fileId 或 path
# 期望 403（T7）
```
