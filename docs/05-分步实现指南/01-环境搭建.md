# 步骤 01：环境搭建

> 分期：Phase 0。  
> 目标：本机用 Docker Compose 拉起 MinIO、MySQL、RabbitMQ、Nginx，并能上传一个测试 mp4。  
> 上一篇：[阅读说明](./00-阅读说明.md)　下一篇：[数据模型初始化](./02-数据模型初始化.md)

## 本步要做什么

只准备基础设施，**不写业务代码**。`vod-api` 与 `vod-worker` 先用占位服务或先不声明，等第 03 步再加。

## 前置条件

- 已安装 Docker Desktop（或 Docker Engine + Compose v2）
- 本机建议 4 核 8 GB 内存
- 工作目录：`lite-vod/`（可放在 `tjxt` 仓库外，避免污染父工程）

## 操作步骤

### 1. 创建目录

```text
lite-vod/
├── docker-compose.yml
├── nginx/
│   └── conf.d/vod.conf
├── sql/
│   └── schema.sql          # 下一步再写，本步可放空文件
└── .env.example
```

### 2. 编写 `.env.example`（勿提交真实密钥）

```bash
MINIO_ROOT_USER=minioadmin
MINIO_ROOT_PASSWORD=minioadmin
MYSQL_ROOT_PASSWORD=change-me
MYSQL_DATABASE=lite_vod
MYSQL_USER=vod
MYSQL_PASSWORD=change-me
VOD_PLAY_SECRET=change-me-play-secret
```

本地复制为 `.env` 后改密码。`.gitignore` 忽略 `.env`。

### 3. 编写 `docker-compose.yml`（本步服务）

| 服务名 | 镜像建议 | 宿主机端口 |
| --- | --- | --- |
| mysql | mysql:8 | 3306 |
| rabbitmq | rabbitmq:3-management | 5672 / 15672 |
| minio | minio/minio | 9000 / 9001 |
| nginx | nginx:alpine | 80 |

注意：

- MinIO 命令使用 `server /data --console-address ":9001"`
- MySQL 挂载 `./sql` 到 `/docker-entrypoint-initdb.d`（下一步的 `schema.sql` 会自动执行；空文件无害）
- Nginx 本步可先反代 MinIO 控制台或返回静态欢迎页，验签逻辑放到第 11 步

### 4. 启动并检查

```bash
docker compose up -d
docker compose ps
```

检查：

- MySQL：`3306` 可连
- RabbitMQ 管理台：`http://localhost:15672`
- MinIO 控制台：`http://localhost:9001`

### 5. 创建 bucket `vod`

任选其一：

- MinIO Console：Buckets → Create → 名称 `vod`
- `mc` 客户端：

```bash
mc alias set local http://localhost:9000 minioadmin minioadmin
mc mb local/vod
```

Bucket **不要**开匿名读。播放一律走 Nginx 签名后再反代（第 11 步）。

### 6. 手工上传测试片

在控制台把任意短 mp4 传到 `vod/raw/test/source.mp4`，确认对象存在即可。路径约定见实现文档第六章。

## 完成标准

- [ ] `docker compose ps` 四个服务均为 healthy / running
- [ ] 已创建 bucket `vod`
- [ ] 控制台或 `mc` 能看到测试对象
- [ ] `.env` 未提交到 Git

## 本步不做

- 不建 `media` 表以外的业务（表在下一步）
- 不写 Spring Boot
- 不配置 HMAC 验签
