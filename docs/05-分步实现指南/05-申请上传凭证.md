# 步骤 05：申请上传凭证

> 分期：Phase 1。  
> 目标：实现 `GET /vod/signature/upload`，生成 `fileId`、落库 `UPLOADING`、返回 MinIO 预签名 URL。  
> 上一篇：[对象存储封装](./04-对象存储封装.md)　下一篇：[确认上传与媒资落库](./06-确认上传与媒资落库.md)

## 本步要做什么

对齐腾讯云 Upload Signature 的使用方式：前端先拿凭证，再直传对象存储，文件流不经过业务机。

## 接口契约

- **方法 / 路径**：`GET /vod/signature/upload`
- **鉴权**：管理端需登录。首期演示可暂不加登录，但代码里预留 Header / 注释，避免以后难改

响应示例：

```json
{
  "fileId": "f7c2a1b0e9d84f6a",
  "uploadUrl": "http://localhost:9000/vod/raw/...?X-Amz-Algorithm=...",
  "objectKey": "raw/f7c2a1b0e9d84f6a/source.mp4",
  "expireAt": 1710000000
}
```

## 处理流程

1. 生成 `fileId`（UUID 去横线或短随机串）
2. 计算 `objectKey = raw/{fileId}/source.mp4`
3. 插入 `media`：`status=UPLOADING(0)`，`object_key` 已填
4. `presignedPutObject`，过期时间写入 `expireAt`（Unix 秒）
5. 返回 DTO

## 操作步骤

### 1. 领域层

- `Media` 实体 / 枚举 `MediaStatus`
- `MediaRepository`：按 `file_id` 查询、插入

### 2. 应用层

`UploadSignatureService.create()` 按上面 5 步实现。  
失败时不要留下无用半截数据：插入失败则不签发 URL。

### 3. Controller

路径前缀 `/vod`。统一响应包装可与天机学堂风格接近，演示也可用直接返回 JSON。

### 4. 验证

```bash
curl -s http://localhost:8080/vod/signature/upload
```

然后：

```sql
SELECT file_id, object_key, status FROM media ORDER BY id DESC LIMIT 1;
```

`status` 应为 `0`。

用返回的 `uploadUrl` PUT 一个小 mp4，MinIO 中应出现对象（完整 commit 在下一步）。

## 完成标准

- [ ] 接口返回四字段齐全
- [ ] 库中有对应 `UPLOADING` 记录
- [ ] 预签名在过期前可 PUT
- [ ] 大文件 Multipart **不做**

## 对照天机学堂

`MediaController` 获取上传签名；`TencentMediaStorage.getUploadSignature()`。Lite VOD 用本接口替换云 SDK。
