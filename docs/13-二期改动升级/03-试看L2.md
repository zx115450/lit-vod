# 03：试看 L2（preview.m3u8）

> 目标：试看用户只能拿到前 N 秒切片清单，无法靠改 URL 拖到正片。  
> 依赖：HLS 产物结构稳定（可在单档或多码率之后做）。  
> 上一篇：[多码率 ABR](./02-多码率ABR.md)　下一篇：[对接天机学堂](./04-对接天机学堂.md)

## 1. 档位回顾

| 档位 | 做法 | 安全性 |
| --- | --- | --- |
| L0 | 短 TTL 签名 | 低：过期前仍可能拉完整流 |
| L1 | 网关按 `exper` 限时断流 | 中：靠网关时钟与实现 |
| **L2** | 另出 `preview.m3u8`，仅含前 N 秒 ts | **高**：正片切片不在清单中 |

首期已有 `exper` 查询参数与签发字段，二期把「试看」落到**独立清单**。

## 2. 目标行为

```text
exper == 0（或未试看）
  → playUrl 指向正片清单
     单档：/hls/{fileId}/index.m3u8
     多码率：/hls/{fileId}/master.m3u8

exper > 0（试看秒数）
  → playUrl 指向 /hls/{fileId}/preview.m3u8
  → preview 内只列出覆盖前 exper（或配置 previewSeconds）的 segment
  → 验签 path 绑定 preview 路径（防改成 index/master 仍用试看 sign）
```

安全关键：**试看签名不得用于正片 path**。  
即 payload 里的 `path=` 必须是 preview 的 URI；网关验签用请求所在资源对应的 signedPath 规则要重新定义清楚。

建议规则：

- 正片签发：`path=/hls/{fileId}/master.m3u8`（或 index）
- 试看签发：`path=/hls/{fileId}/preview.m3u8`
- 网关：校验 query 签名时，用**该次请求所属清单类型**对应的 signedPath  
  - 访问 `preview.m3u8` 及其列出的 ts → 必须用 preview 签发的 sign  
  - 访问正片目录 → 必须用正片签发的 sign  

这样即使用户猜到 `720p/segment_050.ts`，没有正片签名也无法通过。

## 3. 转码侧改动

在 Worker 成功出正片 HLS 后：

1. 按 `previewSeconds`（如 120）选取前若干 ts（按 m3u8 累加 `#EXTINF`）
2. 生成 `preview.m3u8`（相对路径指向**同一批**已上传的 ts，或复制到 `preview/` 目录）
3. 上传 `hls/{fileId}/preview.m3u8`

推荐：**复用正片 ts**，preview 清单只列前缀片段，节省存储。  
多码率时：可为每档生成 preview，或只出 480p 一档试看（产品定）。

## 4. 签发侧改动

`PlaySignatureService.sign(fileId, exper)`：

- `exper <= 0`：path = 正片清单
- `exper > 0`：path = `/hls/{fileId}/preview.m3u8`，并可把 `exper` 写入 query（兼容旧字段）

媒资未 `FINISHED` 仍不可签发。

## 5. 网关改动

| 项 | 说明 |
| --- | --- |
| `PlayPathSupport` | 区分 preview / 正片 signedPath |
| 改写 m3u8 | preview 内相对 ts 同样追加 query |
| 拒绝 | 用试看 sign 访问正片 master/index → 403 |

## 6. 兼容策略

- `VOD_PREVIEW_L2_ENABLED=false`：保持首期（仅 exper 字段，不强制换清单）
- 开启后：新转码任务写 preview；旧媒资无 preview 时试看签发可回退 L1 或返回 409 提示重转

## 7. 验收

- [ ] 试看 playUrl 的 path 为 preview，播放仅前 N 秒有片
- [ ] 试看 sign 访问正片清单或靠后 ts → 403
- [ ] 正片 sign 可完整播放
- [ ] 关闭 L2 后行为与首期一致

## 8. 风险

- preview 与正片共用 ts 时，必须靠**签名 path 绑定**挡住正片 URL
- N 秒与切片边界不对齐：向上取整到完整 ts，文档写清「最多试看到第 K 片结束」
