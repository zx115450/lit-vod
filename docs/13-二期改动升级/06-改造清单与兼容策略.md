## 2. 兼容原则

1. **默认关闭二期行为**：feature flag 打开才改变路径与产物  
2. **首期 API 保留**：`GET /vod/signature/upload`、单档 `index.m3u8` 在关闭 ABR 时仍可用  
3. **存量媒资**：不强制重转；新策略仅作用于新任务  
4. **删除**：继续按 `fileId` 前缀清理，兼容多档与 preview  
5. **密钥**：不新增明文；不把 MinIO 密钥当播放密钥

## 3. 建议 Feature Flag

| 变量 | 默认 | 作用 |
| --- | --- | --- |
| `VOD_UPLOAD_MULTIPART_ENABLED` | false | 允许 multipart API |
| `VOD_ABR_ENABLED` | false | Worker 出多码率 + master |
| `VOD_PREVIEW_L2_ENABLED` | false | 出 preview 并改签发 |
| `VOD_CALLBACK_URL` | 已有 | 天机事件地址 |

## 5. 回滚步骤

1. 配置关闭对应 flag，滚动发布 api / worker  
2. 确认新上传走首期路径、播放 path 恢复  
3. 已生成的 master / preview 可保留（不伤播放若签发已改回需重签）  
4. 天机 `platform` 切回 `tencent` 或旧 base-url  

镜像回滚：沿用首期 CI 的 `IMAGE_TAG` 短哈希回滚方式。
