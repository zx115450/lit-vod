# 二期改动升级：阅读说明

> 面向 Lite VOD **首期闭环已完成后**的能力升级。  
> 对照：[步骤 16](../05-分步实现指南/16-增强与对接天机学堂.md)、[首期 Demo 清单](../09-首期Demo清单.md)、[实现文档](../04-轻量版云点播-Lite-VOD-实现文档.md)。  
> 原则：**一项能力一个分支 / 一 PR**，不要和首期修复、CI 改动混提。

## 何时开始

同时满足再开工：

1. 主路径可演示：上传 → 转码完成 → 签名播放 → 删除
2. 建议步骤 15 的 T1～T8 有记录（脚本或手工验收均可）
3. `main` 上 CI / 部署稳定，二期改动可独立回滚

## 二期目标（相对首期）

| 能力 | 首期 | 二期 |
| --- | --- | --- |

## 推荐实施顺序

```text
01 分片上传（不改播放链路）
 → 02 多码率（Worker + 对象键，播放器自动适应）
 → 03 试看 L2（依赖 HLS 产物结构稳定）
 → 05 指标（可与 01～03 穿插）
 → 04 对接天机（业务侧仓库，最后做）
```

`06` 全程对照：接口兼容、开关、回滚。

## 全局完成标准

- [ ] 大文件可分片直传并走通 commit → 转码
- [ ] 多码率可播，弱网可降档（或至少清单正确）
- [ ] `exper>0` 时无法拖到正片完整内容（L2）
- [ ] 首期整对象上传与单档播放在开关关闭时行为不变
- [ ] 密钥仍仅环境变量 / 配置中心，不进仓库
