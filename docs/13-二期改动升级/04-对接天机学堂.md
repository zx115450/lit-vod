# 04：对接天机学堂（tj-media）

> 目标：在天机侧增加 `LiteVodMediaStorage`，配置切换后上传 / 播放 / 删除走 Lite VOD，无需腾讯云账号。  
> 依赖：Lite VOD 二期能力按需就绪；课表鉴权仍在天机业务服务。  
> 上一篇：[试看 L2](./03-试看L2.md)　下一篇：[可观测与运维增强](./05-可观测与运维增强.md)

## 1. 原则

```text
IMediaStorage
  ├─ TencentMediaStorage   （现网）
  └─ LiteVodMediaStorage   （新增）
```

- 门面方法不变，便于配置切换
- Lite VOD **不负责** `sectionId` / 课权；天机仍先鉴权再向 VOD 要播放签名
- 密钥：`VOD_PLAY_SECRET` 与 MinIO 密钥分离，走 Nacos / 环境变量

## 2. 方法映射

| `IMediaStorage` | Lite VOD |
| --- | --- |
| `getUploadSignature()` | `GET /vod/signature/upload` 或 multipart 初始化 |
| `getPlaySignature(fileId, userId, freeExpire)` | `GET /vod/signature/play?fileId=&exper=`（`freeExpire` → `exper`） |
| `queryMediaInfos(fileId)` | `GET /vod/medias/{fileId}` |
| `deleteFile(fileId)` | `DELETE /vod/medias/{fileId}` |
| 事件（Procedure 结果） | Webhook → 天机接口，或 PullEvents 适配 |

## 3. 配置示例

```yaml
tj:
  media:
    platform: lite-vod   # tencent | lite-vod
    lite-vod:
      base-url: http://vod-api:8080
      # 若天机本地验签 / 调试需要；播放验签在 Lite VOD 网关
      connect-timeout-ms: 2000
      read-timeout-ms: 3000
```

## 4. 改造范围（天机仓库）

| 项 | 说明 |
| --- | --- |
| 新建 `LiteVodMediaStorage` | RestClient / Feign 调 Lite VOD |
| Spring 注入按 `platform` 选择实现 | 与现有 Tencent 实现并列 |
| 上传前端 | 预签名 host 改为 MinIO 公网；注意 CORS |
| 播放前端 | 使用返回的 `playUrl`（已含网关域名） |
| 事件 | 配置 `VOD_CALLBACK_URL` 指向天机收事件接口；幂等按 fileId |

本仓库（Lite VOD）侧：保证 API 契约稳定、错误码语义清晰（404/409/4xx）。

## 5. 联调清单

- [ ] 管理端上传 → Lite VOD 列表 `FINISHED`
- [ ] 学员端有课权可播；无课权在天机被拒（不到 VOD 或仍无有效签名）
- [ ] 过期 / 篡改 playUrl → 403
- [ ] 删除媒资后天机侧与桶内一致
- [ ] 切回 `platform: tencent` 现网不受影响

## 6. 风险

- 上传域名与播放域名 CORS
- 回调超时导致天机状态延迟 → 天机可轮询 `GET /vod/medias/{fileId}` 兜底
- fileId 与天机 mediaId 映射表是否已有：对接时统一主键策略
