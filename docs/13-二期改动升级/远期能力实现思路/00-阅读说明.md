# 远期能力实现思路：阅读说明

> 对应二期阅读说明中的 **「二期不要做（除非单独立项）」**。  
> 本文档只讲**业务边界与实现思路**，不纳入二期排期；真要做需单独立项、单独仓库或单独里程碑。  
> 上级目录：[二期改动升级](../00-阅读说明.md)

## 为什么单独写

这些能力与当前 Lite VOD「点播子集」重叠少、成本高，和二期的 Multipart / ABR / L2 / 天机对接不是一类活。  
写清思路是为了：面试能讲、立项能估、避免二期范围膨胀。

## 和现网 Lite VOD 的关系

```text
Lite VOD（现在）     上传 / 转码 / 点播签名 / HLS 网关
        │
        ├─ 远期可拼：CDN 边缘、DRM license、直播旁路
        │
业务服务（天机等）   课表、订单、试看策略、用户身份
        │
        └─ 永远建议留在业务侧：课权判断
```

## 立项前先问自己

1. 是否已有云厂商 / 开源方案能买或能接，而不是自研？
2. 团队是否有流媒体 / 编解码专项人力？
3. 是否与「私有化点播 Demo」目标一致，还是变成另一个产品？
